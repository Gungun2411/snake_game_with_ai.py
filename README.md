# 🐍 Snake Game in Python (Pygame)

A classic Snake game built using Python and Pygame with a modern UI, menu system, pause feature, and high-score saving.

## 🎮 Features
- Grid-based snake movement
- Food spawning system
- Pause and resume gameplay
- Menu and Game Over screen
- Persistent high score storage
- Keyboard controls (Arrow keys / WASD)

## 🛠 Technologies Used
- Python 3
- Pygame

# Snake (Professional)

A polished, playable Snake game written in Python using `pygame`.

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python snake.py
```

Controls:
- Arrow keys or WASD: move
- P or Space: pause / unpause
- R: restart (on game over)
- M: return to menu (on game over)
- Q or close window: quit

High score is saved to `snake_highscore.txt` in this folder.
